    Attack your AI agent before your users do.

    Agent Reliability Lab throws 229 real attacks and failures at your AI agent: jailbreaks, prompt injection, leaked secrets, poisoned documents, broken tools. It tells you in plain English what broke, shows the exact conversation, suggests the fix, and blocks the release when a new version gets worse.

    pip install agent-reliability-lab
    Open the live demo Get started in 5 minutes GitHub

    AI agents fail in ways unit tests never see.

    A one-line prompt change or a model upgrade can make your agent print its system prompt, follow instructions hidden in a web page, issue a refund nobody asked for, or give up the moment a tool times out.

    A few manual chats prove nothing, and agents are random: the same question passes today and fails tomorrow. You need to attack it the way real users and attackers will, many times, and measure it like an engineer.

    What it catches

    Six ways agents break in production

    1. Leaked secrets

      System prompts, API keys and other customers' data, caught even when reversed, spaced out, re-punctuated or base64-encoded.

    2. Jailbreaks and injection

      Role-play, authority spoofing, multi-turn manipulation and instructions hidden in documents, pages, tools and memory, in 5 languages.

    3. Dangerous actions

      Refunds, emails and deletions the user never asked for, destructive code and data sent to outside links.

    4. Broken tools

      Errors, timeouts, rate limits, bad or partial data and schema changes injected into your real tools, to see if the agent recovers.

    5. Wrong answers

      Invented facts, ignored documents and harmful advice, graded by an LLM judge only after the cheap checks pass.

    6. Silent regressions

      Every version compared with significance tests. A change that makes the agent measurably worse fails the pull request.

    How it works

    From install to a gated release in four steps

    1. 01

      Find your agent

      arl init detects it (OpenAI Agents SDK, LangGraph, LangChain, CrewAI, LlamaIndex, PydanticAI, MCP, HTTP or a plain function) and plants a secret canary.

    2. 02

      Attack it

      Attack packs matched to what your agent can do: RAG, tools, memory, multi-agent, code, browsing, multimodal. Anything that can't apply is skipped with the reason.

    3. 03

      Read the findings

      Failures grouped into a few problems in plain English, each with the attack, the reply and a fix. Replay any conversation step by step in the dashboard.

    4. 04

      Gate every change

      arl check after each edit, the GitHub Action on each pull request. Only statistically significant regressions block.

    The dashboard

    Every run is an investigation file

    History with confidence intervals, plain-English findings, OWASP and capability coverage, step-by-step replays with injected faults, and side-by-side version comparisons. arl ui runs it locally; arl ui --export publishes a read-only copy.

    What it found

    LLM gateway guardrails

    30% → 100%

    The trained injection classifier stopped only 51 of 170 attacks, and red-teaming found 122 new bypasses. An output canary rule closed the gap with zero false blocks.

    Long-document Q&A agent

    116 / 116

    Every attack resisted, and a control scenario proved it still answers correctly. But 4 real defects: a search error or rate limit crashes it, and a hung search hangs the agent.

    Works where you build

    One engine, four ways to use it

    Command line

    arl check
arl run --suite builtin:standard
arl ui

    Claude Code plugin

    /plugin marketplace add sivram04/agent-reliability-lab
/plugin install arl@agent-reliability-lab

    Checks the agent after every change and asks the assistant to fix what broke.

    MCP server

    {"mcpServers": {"arl":
  {"command": "arl", "args": ["mcp"]}}}

    For Cursor, VS Code and any MCP client.

    CI / CD

    - uses: sivram04/agent-reliability-lab@main
  with:
    suite: builtin:standard

    Or JUnit XML for GitLab, Jenkins, Azure.
